## 关于"根技术"的定义

这里说的**根技术（root technology）**，不是某个具体产品或算法，而是**一类可迁移的设计原则**：它回答"为了让一个 AI Agent 在故障感知/恢复里可靠，必须在体系里放进哪些非 LLM 的机制"。判断一项东西是不是根技术，看三条：

1. **可迁移**：换到网络设备、数据库、微服务、甚至物理系统，原则仍然成立。
2. **不可由 LLM 单独替代**：如果只靠 LLM 的概率生成，这一层会塌（confirmation bias、幻觉、伪造时间、记忆污染……）。
3. **有理论谱系**：能追溯到一门成熟的学科（科学哲学、因果推断、形式化方法、安全工程），不是工程 trick。

7 项根技术全部满足这三条。CausalFusion 不是第 8 项根技术，而是**第 1 项（反证优先）+ 第 2 项（结构因果）的学术形式化版本**——它独立成篇是因为它同时把"为什么这么做是对的"这件事，用因果发现的经典度量（SHD）给了量化证据。
